# Web 控制台

[English](web-console.md) · [**中文**](web-console-zh.md)

浏览器打开 <http://127.0.0.1:8787/>。整个前端（Next.js 静态导出）都被编译进二进制，
所以部署仍然只是一个可执行文件加 `config.yaml`——运行时没有 `node_modules`，
也没有会丢的静态资源目录。

技术栈：Next.js 15（`output: "export"`）、React 18、TypeScript、Tailwind CSS v4，
以及一套自研小组件。Mobile First（手机上是底部标签栏，桌面是置顶粘性导航）；
中英完整双语；深浅色跟随系统并可手动覆盖。偏好存在 `localStorage`，服务端不存任何东西。

## 页面

| 页面 | 能做什么 |
| --- | --- |
| **总览** | 忙/闲状态与下次切换倒计时、请求/错误/流式/重试计数、套餐节省与现金支出、每个端点的健康与冷却、三个额度窗口的进度条（含外推与阈值刻度）、余额、token、缓存命中、延迟、最近错误。每 2 秒刷新，可暂停。 |
| **端点** | 增删改端点；**拖拽行以调整消耗顺序**；**一键启用/禁用并立即生效**；**复制端点**；复制现成的 `curl`；执行**连通性自检**（密钥、`/models`、额度或余额、一次最小请求），并给出基于实测的建议。 |
| **策略** | 路由模式、闲时倾向、充裕阈值与外推、耗尽阈值、同层选择、会话亲和、全部冷却与跳过参数、兼容层开关。含**候选顺序预览**，按当前时钟与额度模拟一次请求。 |
| **模型库** | [模型库](model-library-zh.md)：基准参数、别名，以及每个模型正被哪些端点使用。 |
| **设置** | 监听地址、端口、并发、超时、请求体上限、网关密钥、日志级别与文件、可直接复制的客户端片段、**备份 / 导出 / 导入**，以及原始 YAML 编辑。 |

每个可配置项旁边都有一个 `?`，点开就是该字段在当前语言下的内联说明——
目标是改配置时不需要离开页面去翻文档。

## 安全边界

- 控制台是一个**无鉴权的本地管理面**，和 `/router/stats` 一样。它默认只绑定
  `127.0.0.1`；请保持默认，或先设置 `server.client_keys`——`/api/*` 会同样要求该密钥。
- **密钥是只写的。** `GET /api/config` 永远不返回明文密钥，只返回占位符；保存时回传
  该占位符表示「保持原值不变」。`env:VAR` 与 `file:path` 引用会原样显示。
- 静态资源拒绝路径穿越；备份的读取、删除与恢复只接受 `config-*.yaml` 文件名。

## 一次保存如何落到磁盘

所有写入都走同一条路径，这也是控制台与手工编辑的文件不会互相打架的原因：

1. 把编辑结果渲染成 YAML；
2. 用 `config::parse`——**运行时同一个解析器**——校验，所以控制台能存进去的，
   路由器一定能加载；
3. 校验失败则返回 400，磁盘上的文件**一个字节都不动**；
4. 校验通过先备份一份带时间戳的副本到 `backups/`，再原子写入
   （同目录临时文件、fsync、rename）；
5. 热加载运行中的配置，页面立即反映生效结果。

> **注意。** 保存会重写 `config.yaml`，且**不保留手写注释**。每次写入前都会自动备份。
> 需要长期保留注释，请维护在 `config.example.yaml` 里，或使用「导出」。

## 构建前端

构建脚本每次都会重建控制台再内嵌：

```powershell
.\build.ps1            # 先 npm run build（web/ -> web/out），再 cargo，最后打包 dist
```

```bash
./build.sh
```

只改 Rust 时直接调用 cargo：它按现有 `web/out` 重新内嵌。只有前端改动才需要重建前端。
